### What I'm working on

I'm exploring how AI agents can plug into the daily workflows of local businesses — beauty salons, pilates studios, yoga spaces — without replacing their existing tools. Think "add-on intelligence", not "yet another SaaS platform".

Right now I'm deep in the **Claude Code plugin ecosystem**, building reusable skills and automation that make coding agents genuinely useful.
